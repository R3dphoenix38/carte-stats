# Carte de stats

Appli web installable (PWA) : une carte radiale de tes capacités (Mental, Vitesse, Force, Endurance, Agilité), notées sur 100 par rapport à des barèmes et aux records du monde, avec des ligues (Départ, Élite amateur, Pro).

- `index.html` : l'appli
- `catalog.js` : les exercices, paliers et records de référence
- Les données de l'utilisateur sont enregistrées sur l'appareil (bouton de sauvegarde / restauration dans la fiche).
